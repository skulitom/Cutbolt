Cutbolt: local video editing for AI agents

Cutbolt is a video editing engine for AI agents. Claude Code or another MCP client turns recorded footage into a finished edit on your own machine: it arranges shots, tightens dialogue, adds captions and titles, mixes sound and exports H.264 or lossless masters. Every saved edit has a revision, so the agent can inspect a change, retry a request safely or undo a decision. It is a single Rust executable with a local MCP server over stdio and a JSON command line, free and MIT-licensed. It needs FFmpeg and ffprobe, which you install separately, and no account or hosted service.
