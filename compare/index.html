Cutbolt comparisons

We make Cutbolt, a free, MIT-licensed video editing engine with a local MCP server. This page compares it with other video editing tools for AI agents. It says which numbers we measured and which we read from the other tools' code and docs, and when it was last checked.

Local video editing MCP servers for AI agents, and hosted alternatives: 7 compared

Checked 17 October 2026. Four are local MCP servers that edit your files: Cutbolt (18 tools by default), Kinocut (formerly mcp-video; 203 tools), claudeclip (31) and video-edit-mcp (34). Video Jungle MCP edits on Video Jungle's servers, Vlexor has a hosted engine plan each edit and renders it on your machine (its package could not be installed as its README says on 17 October), and HyperFrames renders new videos from HTML. We measured Cutbolt over MCP on one Windows PC, in six runs across its 0.4.0 release and main: a cut of a 720p test clip exported exactly the expected 150 source frames in order, resending the same edit returned its original receipt, undo restored the earlier cut, and repeated H.264 exports of the cut were byte-identical with one FFmpeg build (main also fixes a repeatability case that 0.4.0 still has). We read the other six from their code and docs without running them.
